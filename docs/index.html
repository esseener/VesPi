常见问题

下载前想知道的事

关于依赖、权限、数据与更新。

需要先安装 Node、Bun 或 OMP 吗？
不需要。VesPi 自带私有 OMP 内核，随安装包一起交付，不写入系统 PATH，也不读取全局安装的 omp。装完即可使用。
内核是什么？我可以换成别的吗？
内核是 Oh My Pi（OMP）的 Windows 预编译二进制，以 --profile vespi --mode rpc-ui 启动。 内核版本随应用锁定，避免与界面版本错配；升级内核由应用内更新完成，无需手动替换文件。
它会自动修改我的项目或系统环境吗？
不会。所有文件写入与命令执行都经过权限审批；你可以逐次确认，也可以按工具、按目录设置放行规则。 未标记信任的仓库只能收紧权限，不能放宽。
我的数据存在哪里？
会话记录、用量统计与配置保存在本机用户目录，不会上传。删除会话后，历史统计仍会保留。
怎么更新？会不会丢配置？
应用内可检查并下载更新，界面与内核分别升级。安装包支持覆盖安装，会话记录与配置自动保留。
为什么安装时会有安全提示？
因为当前构建未做代码签名，Windows 会对未签名安装包给出提示。你可以用随版本发布的 SHA256SUMS.txt 校验安装包完整性，或直接从源码自行构建。
只有 Windows 版本吗？
当前正式支持 Windows x64。由于内核按平台单独提供，其他平台需要对应的内核构建后再行支持。
